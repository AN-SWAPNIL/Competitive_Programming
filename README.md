# Competitive Programming

A compact C++ toolkit for contests: starter templates, editor snippets, tested
implementations of common algorithms and data structures, and practice
material.

## What's included

- [`Templates/`](Templates/) — contest templates and reference notes.
- [`Snippets/`](Snippets/) — VS Code snippets for the main template, debugging,
  random test generation, and AtCoder Library.
- [`Competitive-Programming/`](Competitive-Programming/) — the algorithm
  library, grouped into graphs, dynamic programming, data structures, strings,
  mathematics, geometry, and classic problems.
- [`Competitive-Programming-A-Complete-Guideline/`](Competitive-Programming-A-Complete-Guideline/)
  — an additional competitive-programming reference.
- [`Workshops/`](Workshops/) — workshop notes and examples.

## Quick start

Clone the repository with its submodules:

```bash
git clone --recurse-submodules https://github.com/AN-SWAPNIL/Competitve_Programming.git
```

If you already cloned it:

```bash
git submodule update --init --recursive
```

Copy **// Main Template** [`Templates/00_template.cpp`](Templates/00_template.cpp) for a new
solution in CPP, or enable the snippets in VS Code. Browse the algorithm library when
you need a known implementation, then adapt and test it against the problem's
constraints.
